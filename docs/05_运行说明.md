# 05 项目运行说明

## 5.0 三步跑通（TL;DR）

```bash
# 第 1 步：进入项目根目录
cd tourism_viz_project

# 第 2 步：安装依赖（仅首次，约 1—2 分钟）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 第 3 步：一键运行全部模块
python run_all.py
```

运行结束后，**双击** `output/全国旅游业发展可视化分析大屏.html` 即可看到大屏
（无需任何后端服务、无需联网）。

---

## 5.1 项目目录约定

运行前请确认目录结构如下（`data/`、`output/`、`docs/` 在首次运行时自动创建）：

```text
tourism_viz_project/
├─ run_all.py               ← 一键运行入口
├─ requirements.txt
├─ src/
│  ├─ config.py             ← 全局配置（可调参数都在这里）
│  ├─ dataset_builder.py
│  ├─ 01_preprocess.py
│  ├─ 02_analysis_charts.py
│  ├─ 03_kmeans_cluster.py
│  ├─ 04_dashboard.py
│  └─ build_map_asset.py
├─ assets/
│  ├─ echarts.min.js        ← 离线 ECharts 5
│  └─ maps/china_std.js     ← 离线中国地图
├─ data/                    ← 自动生成
├─ output/                  ← 自动生成
└─ docs/                    ← 本文档
```

> **重要**：所有脚本的路径都基于 `src/config.py` 中的 `PROJECT_ROOT` 推导，
> 因此**在哪个工作目录执行都可以**，但推荐在项目根目录执行 `python run_all.py`。

## 5.2 方式一：一键运行（推荐）

```bash
python run_all.py
```

执行链路（任何一步失败即中断并提示）：

| 步骤 | 模块 | 主要动作 | 输出 |
|------|------|----------|------|
| STEP 00 | 数据集构建 | 内置数据 → `data/*.csv`（仅首次生成，已存在则跳过） | 4 个原始 CSV |
| STEP 01 | 数据预处理 | 格式统一 → 缺失填补 → 异常检测修正 → 派生指标 → 标准化 → 多源整合 | `data/cleaned_*.csv`、`merged_province_full.csv`、预处理报告 |
| STEP 02 | 统计分析绘图 | 9 张静态图 | `output/charts/图4-1 ~ 图4-9` |
| STEP 03 | K-Means 聚类 | K 值搜索 → 分层 → 河南定位 | `output/cluster/*`、`图4-10 ~ 图4-12`、聚类报告 |
| STEP 04 | 可视化大屏 | 5 个 ECharts 图表 + KPI + 梯队徽章拼装 | `output/全国旅游业发展可视化分析大屏.html` |

### 可用参数

```bash
python run_all.py --force-data    # 强制重建原始 csv（覆盖 data/ 下的原始表，用于复现数据）
python run_all.py --skip-data     # 跳过 STEP 01 预处理，直接从绘图开始（改图表样式时提速用）
```

## 5.3 方式二：分步运行（调试 / 写论文时用）

各模块可独立执行，适合边改边看：

```bash
# 只生成原始数据集
python src/dataset_builder.py

# 只做数据预处理（输出清洗结果 + 数据质量报告）
python src/01_preprocess.py

# 只画静态图表（图4-1 ~ 图4-9）
python src/02_analysis_charts.py

# 只做聚类（控制台会打印 K 值搜索表 + 四梯队明细 + 河南定位）
python src/03_kmeans_cluster.py

# 只重建大屏（改样式时最常用）
python src/04_dashboard.py

# 只重建离线地图资源（地图资源缺失时执行一次）
python src/build_map_asset.py
```

> **提示**：`03_kmeans_cluster.py` 与 `04_dashboard.py` 依赖 `data/cleaned_*.csv`，
> 若 `data/` 为空请先执行 `01_preprocess.py`（或 `dataset_builder.py`）。

## 5.4 查看结果

### 5.4.1 打开可视化大屏（最终交付物）

**方式 A（最简单）**：在文件管理器中进入 `output/`，**双击**
`全国旅游业发展可视化分析大屏.html`。

**方式 B（命令行）**：

```bash
# Windows
start "" "output/全国旅游业发展可视化分析大屏.html"
# macOS
open "output/全国旅游业发展可视化分析大屏.html"
# Linux
xdg-open "output/全国旅游业发展可视化分析大屏.html"
```

> ✅ **完全离线**：ECharts 与地图都是本地 `assets/` 文件，**拔掉网线也能正常显示**。
> ✅ **可整目录拷贝**：把整个 `output/` 文件夹拷到答辩电脑（甚至 U 盘）即可演示。
> ✅ **自适应缩放**：大屏基于 1920×1080 设计画布，用 CSS `transform: scale()` 自动适配任意分辨率。

**大屏交互方式**：

| 元件 | 交互 |
|------|------|
| ② 全国热力地图 | 鼠标悬浮省份 → 弹出旅游收入/游客量/全国占比；**支持滚轮缩放与拖拽平移** |
| ③ 趋势分析 | 十字准星联动，同时读取左右双轴数值 |
| ④ 省份排名动态条形图 | 自动播放 10 帧（2015→2024），也可拖拽时间轴或点 ▶ 播放 |
| ⑤ 节假日对比 | 悬浮查看"春节/五一/国庆"三节收入与人次 |
| ⑥ 热门城市 TOP10 | 悬浮查看城市收入 |

## 5.5 参数调整指引（改一处即全局生效）

所有可调参数集中在 **`src/config.py`**，写论文"参数设置"时可直接引用：

| 参数 | 默认值 | 含义 | 调大 / 调小的效果 |
|------|-------:|------|-------------------|
| `RANDOM_SEED` | 42 | 随机种子 | 改值会得到不同的模拟数据（不推荐改） |
| `IQR_K` | 3.0 | IQR 异常检测倍数 | 调到 1.5 → 疫情真实低谷会被误判为异常 |
| `ZSCORE_TH` | 3.0 | Z-Score 阈值 | 调小 → 检出更多异常 |
| `KMEANS_K_MIN` / `KMEANS_K_MAX` | 3 / 6 | K 的有效候选区间 | 决定"梯队数"的取值范围 |
| `KMEANS_SCORE_WEIGHTS` | (0.5, 0.25, 0.25) | 轮廓系数 / CH / (1−DB) 的权重 | 调整择优偏好 |
| `KMEANS_K` | `None` | 写死 K 值 | 设为 4 可跳过自动择优，直接使用 4 类 |
| `ANALYSIS_YEAR` | 2024 | 截面分析年份 | 影响地图/排名/城市/聚类的年份 |
| `TOP_N_CITY` | 10 | 城市模块展示数量 | — |
| `TOP_N_PROVINCE` | 15 | 排名图展示省份数量 | — |

**其他常用调整位置**：

| 想改什么 | 改哪里 |
|----------|--------|
| 大屏配色 | `config.py` 的 `DARK` 字典 |
| 静态图配色 | `config.py` 的 `PALETTE` / `REGION_COLORS` |
| 聚类使用的特征 | `03_kmeans_cluster.py` 顶部的 `FEATURES` |
| 大屏面板高度 / 布局 | `04_dashboard.py` 的 `build_html()` |
| 地图视觉映射配色 | `04_dashboard.py` 的 `chart_map()` 中 `visual_map_opts.range_color` |
| 界面文案 / 标题 | `04_dashboard.py` 的 `panel()` 调用处 |

## 5.6 常见问题（FAQ）

| 现象 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'pandas'` | 依赖未装或装到了别的解释器 | `pip install -r requirements.txt`；确认 `python -V` 与 `pip -V` 指向同一环境 |
| 图表里中文显示成方块 | 系统无中文字体 | 见《02 环境安装清单》2.4 节 |
| 大屏地图一片空白/灰底 | `output/assets/maps/china_std.js` 缺失 | `python src/build_map_asset.py`，再 `python src/04_dashboard.py` |
| 双击 HTML 后图表不显示 | 浏览器禁用了本地 JS | 换用 Chrome/Edge；或确认 `output/assets/` 目录随 HTML 一起存在 |
| `FileNotFoundError: data/cleaned_province.csv` | 跳过了预处理直接跑绘图 | 先执行 `python src/01_preprocess.py` |
| 想重新生成一套数据 | 需要覆盖原始 CSV | `python run_all.py --force-data` |
| 大屏在投影仪上被裁切 | 分辨率非 16:9 | 大屏已做 `transform: scale()` 自适应，建议浏览器按 `F11` 全屏 |
| Excel 打开 CSV 中文乱码 | 编码 | 项目统一 `utf-8-sig`，用 Excel 直接双击打开即可；若仍乱码请用"数据→从文本导入"选 UTF-8 |
