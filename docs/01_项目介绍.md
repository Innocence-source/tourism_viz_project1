# 01 项目介绍

## 1.1 项目名称与定位

**项目名称**：基于 Python 的全国旅游业发展可视化分析系统

**英文名称**：National Tourism Development Visualization & Analysis System based on Python

**项目性质**：本科毕业设计（数据分析与可视化方向）

**一句话定位**：以 2015—2024 年全国及 31 个省级行政区的旅游经济数据为对象，用 Python 完成
「**数据预处理 → 统计分析 → 聚类挖掘 → 交互式可视化大屏**」的完整闭环，
最终交付一个**双击即开、完全离线**的深色主题数据大屏。

---

## 1.2 研究背景与意义

### 1.2.1 背景

- 旅游业是国民经济战略性支柱产业。2019 年全国旅游总收入达 6.63 万亿元，
  占 GDP 比重约 6.7%；2020—2022 年受疫情冲击出现断崖式下跌（2022 年谷值仅 2.04 万亿元），
  2023 年起进入复苏通道，2024 年恢复至 5.75 万亿元。
- 与此同时，旅游经济存在显著的**区域不均衡**：2024 年东部 11 省贡献了全国约 **42.7%**
  的旅游收入，而西部 12 省仅占 **29.6%**；省际之间的"游客规模"与"人均消费"也长期错配。
- 传统旅游统计多以**静态报表**呈现，缺乏交互、缺乏地理维度、缺乏对省际差异的分层刻画，
  难以支撑政策研判与产业定位。

### 1.2.2 意义

| 维度 | 价值 |
|------|------|
| **理论意义** | 将统计描述（趋势/对比/相关性）与无监督学习（K-Means 分层）结合，构建"总量—结构—层级"三位一体的旅游经济评价框架 |
| **实践意义** | 产出可交互的决策看板，支持"哪个省在什么梯队、差距在哪、节假日市场如何波动"等问题的快速回答 |
| **方法意义** | 完整演示 Python 数据科学工具链（Pandas → Scikit-learn → Pyecharts）在行业分析中的工程化落地路径 |

## 1.4 数据来源与口径说明（重要）

本项目的 4 张数据表为 **「公开量级锚定 + 确定性模型生成」的模拟数据集**，
**非官方统计数据**，仅用于方法演示与毕业设计。

生成逻辑（见 `src/dataset_builder.py`）：

1. 以 31 个省级行政区 **2019 年**的旅游总收入 / 接待游客量 / GDP / 常住人口为**锚点**；
2. 乘以全国年度景气指数（收入指数、游客量指数、GDP 指数、人口指数）扩展到 2015—2024 十年；
3. 叠加**固定随机种子（seed=42）**的轻微扰动 → **结果完全可复现**；
4. **刻意注入少量缺失值与异常值**，使第 3.3 节的数据预处理有真实的清洗对象
   （共 8 处缺失、6 处异常，详见《03 数据集说明》）。

> **诚实声明**：论文中引用具体数值时，请注明"本文采用按公开量级构造的模拟数据集，
> 结论用于方法验证，不代表官方统计结果"。这一声明既能避免学术风险，也符合 3.1 节的写作要求。

## 1.6 项目特点

| 特点 | 说明 |
|------|------|
| **全离线** | 不引用任何 CDN、不调用任何在线地图瓦片服务、不内嵌任何 API Key，断网可用 |
| **可复现** | 固定随机种子 42，任何机器上运行结果完全一致 |
| **一键运行** | `python run_all.py` 一条命令跑完全部 4 个模块 |
| **地图规范** | 采用国家标准行政区划底图，含 34 个省级行政区（含台湾省、香港、澳门）+ 南海诸岛九段线 |
| **参数集中** | 所有可调参数集中在 `src/config.py`，改一处即全局生效 |
| **论文友好** | 静态图为 150 dpi PNG 可直接插图；每张图均有配套文字描述（文档 06） |
| **控制台输出** | 聚类全过程（K 值搜索表、梯队划分、河南定位）均打印到控制台，便于截图写入论文 |

## 1.7 已知限制（主动说明，避免答辩被追问）

1. **数据为模拟数据**，非官方统计，结论不代表真实产业状况（已在 1.4 声明）。
2. **聚类特征仅 2 维**（旅游收入 + 接待游客量）。维度低、解释性强，是刻意的取舍；
   若扩展到人均消费、A 级景区数等维度，需重新论证 K 值。
3. **K 值采用区间择优（K∈[3,6]）而非全局最优**。原因：全局最优为 K=2（轮廓系数 0.6269），
   但 K=2 退化为"强/弱"二分，无法支撑"发展等级划分"的论述目标。该处理已在
   `output/cluster_report.txt` 与 `config.py` 中显式说明，属于**有理由的工程决策**而非疏漏。
4. **港澳台无统计数据**：统计口径为 31 个省级行政区，港澳台在地图上以中性色绘制
   （保证领土完整表达），悬浮提示显示"暂无统计数据"。
