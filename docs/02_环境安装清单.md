# 02 项目环境安装清单

## 2.1 运行环境要求

| 项 | 要求 | 本项目验证环境 |
|----|------|---------------|
| 操作系统 | Windows / macOS / Linux 均可 | Windows 11（联想小新 16） |
| **Python** | **3.9 及以上** | **3.13.12** |
| 磁盘空间 | ≥ 200 MB（含 ECharts 与地图资源） | — |
| 网络 | **仅首次准备依赖时需要**；运行阶段**完全离线** | — |

> **注意**：Python 3.7 及以下会因 `from __future__ import annotations` 与
> `list[str]` 类型标注等新语法报错，请务必使用 3.9+。

## 2.2 依赖清单（pip 安装列表）

### 2.2.1 完整清单

| 包名 | 版本要求 | 本项目版本 | 用途 |
|------|----------|-----------|------|
| `pandas` | ≥ 1.5.0 | 3.0.6 | 数据处理核心：读取/清洗/分组/透视/合并 |
| `numpy` | ≥ 1.23.0 | 2.5.3 | 数值计算、数组运算、相关系数 |
| `matplotlib` | ≥ 3.6.0 | 3.11.2 | 静态图表绘制（柱/折线/散点/热力图） |
| `seaborn` | ≥ 0.12.0 | 0.13.2 | 统计可视化封装（回归散点、相关系数矩阵热力图） |
| `scikit-learn` | ≥ 1.2.0 | 1.9.1 | K-Means 聚类 + 轮廓系数/CH/DB 评价指标 |
| **`pyecharts`** | **≥ 2.0.0（须 2.x）** | **2.1.0** | **交互式图表 + 可视化大屏（核心）** |

> `pyecharts` 1.x 与 2.x 的 API 差异较大（如 `InitOpts`、`Timeline` 的写法），
> **本项目基于 2.1.0 编写，请勿使用 0.x/1.x**。

### 2.2.2 一键安装命令

```bash
# 方式一：使用 requirements.txt（推荐）
pip install -r requirements.txt

# 方式二：国内网络慢时加清华镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方式三：手动逐个安装
pip install pandas numpy matplotlib seaborn scikit-learn pyecharts

# 方式四：已验证的精确版本（最稳妥，与本文档数据完全一致）
pip install "pandas==3.0.6" "numpy==2.5.3" "matplotlib==3.11.2" \
            "seaborn==0.13.2" "scikit-learn==1.9.1" "pyecharts==2.1.0"
```

> 若使用 Anaconda：`conda install pandas numpy matplotlib seaborn scikit-learn`
> 后单独 `pip install pyecharts`。

### 2.2.3 `requirements.txt` 内容

```text
pandas>=1.5.0          # 数据处理核心
numpy>=1.23.0          # 数值计算
matplotlib>=3.6.0      # 静态图表
seaborn>=0.12.0        # 统计可视化（回归散点、热力图）

pyecharts>=2.0.0       # 交互式图表 + 可视化大屏（需 2.x，本项目用 2.1.0）
```

## 2.3 离线资源（随项目提供，无需安装）

大屏要"双击即开、断网可用"，依赖两个本地文件，**已随项目放在 `assets/` 目录**：

| 文件 | 大小 | 作用 | 缺失时的生成方式 |
|------|------|------|-----------------|
| `assets/echarts.min.js` | ≈ 1.0 MB | ECharts 5 运行库（Pyecharts 的渲染引擎） | `curl -L -o assets/echarts.min.js https://assets.pyecharts.org/assets/v5/echarts.min.js` |
| `assets/maps/china_std.js` | ≈ 0.57 MB | 标准中国地图（含 34 个省级行政区 + 南海诸岛九段线），以 `echarts.registerMap('china', …)` 形式离线注册 | `python src/build_map_asset.py`（自动下载 GeoJSON 并生成） |

运行时 `src/04_dashboard.py` 会把这两个文件**自动同步**到 `output/assets/`，
因此 `output/` 目录可以整体拷贝到任意机器（含无网络的答辩电脑）直接演示。

### 地图规范说明

- 底图数据源：`https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`（标准行政区划 GeoJSON）；
- **包含 34 个省级行政区**：23 省 + 5 自治区 + 4 直辖市 + 台湾省 + 香港特别行政区 + 澳门特别行政区；
- **包含南海诸岛九段线要素**（`adcode = 100000_JD`），保证领土完整表达；
- **全程不使用** Google / OSM / Mapbox 等在线瓦片服务，**不内嵌**任何地图 API Key。

## 2.4 中文字体（Windows 通常已具备）

Matplotlib 绘制中文若不配置会显示方块。`src/config.py` 内置了**自动探测**逻辑，
按以下顺序查找可用字体，命中即用：

```
Microsoft YaHei（微软雅黑）→ SimHei（黑体）→ Source Han Sans CN
→ Noto Sans CJK SC → WenQuanYi Zen Hei → PingFang SC → Arial Unicode MS
```

- **Windows**：默认自带微软雅黑，**无需任何额外操作**；
- **macOS / Linux**：若提示"未找到中文字体"，可执行
  `sudo apt install fonts-noto-cjk`（Ubuntu）或在 `CN_FONT_CANDIDATES` 中补充本机字体名。
- 运行时会打印实际生效的字体，例如：`[字体] Matplotlib 中文字体已设置为：Microsoft YaHei`。

## 2.5 安装自检

安装完成后执行以下命令，**全部打印 `OK` 即为环境就绪**：

```bash
python -c "
import pandas, numpy, matplotlib, seaborn, sklearn, pyecharts
print('pandas      ', pandas.__version__)
print('numpy       ', numpy.__version__)
print('matplotlib  ', matplotlib.__version__)
print('seaborn     ', seaborn.__version__)
print('scikit-learn', sklearn.__version__)
print('pyecharts   ', pyecharts.__version__)
"
```

预期输出（版本号允许更高）：

```text
pandas       2.x / 3.x
numpy        1.2x / 2.x
matplotlib   3.6+
seaborn      0.12+
scikit-learn 1.2+
pyecharts    2.1.0        ← 必须是 2.x
```

### 常见安装问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `pip` 下载超时 | 默认源在国外 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 安装 `pyecharts` 后报 `ImportError: cannot import name 'InitOpts'` | 装成了 1.x 或 0.x | `pip install -U "pyecharts>=2.0"` |
| 地图不显示（一片空白/灰色） | `assets/maps/china_std.js` 缺失 | 执行 `python src/build_map_asset.py` |
| 图表中文变方块 | 系统无中文字体 | 见 2.4 节 |
| 中文 CSV 用 Excel 打开乱码 | 编码问题 | 项目统一使用 `utf-8-sig`，Excel 可直接正常打开 |
